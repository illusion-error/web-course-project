# 正式课程要求

依据用户提供的完整课程说明，替代此前截图草案。

- 自选主题；至少四页，导航有效。
- 学生自己的内容；语义化、可访问的标记；手机可用的响应式布局。
- 至少一个交互；在真实线上地址运行。
- Git 历史体现整个学期真实、持续开发，单晚创建的历史不能替代过程。
- 不要求服务端编程或数据库。
- 过程 20%，项目 40%，笔试 25%，答辩 15%；0–100 分，60 分及以上通过。
- 项目检查链接、图片、无占位内容、内容归属、设计适用性和手机表现。
- 笔试考阅读陌生代码、定位错误、判断问题层次及解释技术选择。
- 答辩解释作品与选择并回答问题。
- AI 使用被期待并纳入教学，考察学生能否阅读、验证、纠正并解释；作者无法解释的作品不能通过。

当前实施方案见 [详细实施计划](IMPLEMENTATION-PLAN.md)。
