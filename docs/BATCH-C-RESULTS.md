# 批次 C：搜索与筛选

本地验收日期：2026-11-01。页面：`site/discover.html`。

## 使用方式

输入名称、选择题材和心情，然后点击“查找作品”或在搜索框按 Enter。三个条件取交集；留空表示不限。中文名、原名均可搜索，去除首尾空格，英文忽略大小写。不会发出搜索网络请求。

地址参数为 `q`、`genre`、`mood`，后两项使用界面中的中文值。提交产生浏览器历史记录，重复提交相同条件不重复添加记录。刷新、前进/后退和从详情页使用浏览器返回，都恢复已提交条件。无效题材、心情和空白搜索自动归为不限并清理地址。

两个清除按钮均清空三个条件并将焦点放回搜索框。结果区域通过 `role=status` 和 `aria-live=polite` 通知变化；普通提交不主动移动焦点。

## 无 JavaScript 与范围

源码检查：全部 6 张卡片由 HTML 提供；筛选表单默认 hidden，仅 JS 成功初始化后显示；noscript 解释筛选不可用。没有用 JSON 冒充数据库。未在本轮关闭浏览器 JS 做实机测试。

手机检查为浏览器 360px 视口，不能代替真实手机。正式公网部署、收藏清单仍分别属于 E、D；本批次不宣称完成这些项目。
