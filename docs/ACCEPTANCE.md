# 最终验收清单

以下均为待做事项，不是测试结果。后端部分仅适用于选择动态扩展后的版本。

- [ ] 已取得课程最终书面要求，明确框架、后端、AI、提交方式与期限。
- [ ] 首页、文章列表、详情、项目、关于页面均有真实内容。
- [ ] 页面标题、标题层级、导航、表单 label、图片 alt 正确。
- [ ] 360、768、1440px 下无意外横向溢出；200% 缩放可操作。
- [ ] 键盘可以完成导航和搜索，焦点清晰可见。
- [ ] 搜索命中、无结果、中文、空输入均处理正确。
- [ ] 筛选状态可理解，链接和浏览器返回按钮工作正常。
- [ ] 收藏刷新后保留；明确只保存在当前浏览器；存储不可用时可降级。
- [ ] 异步请求覆盖加载、成功、空数据、失败、重试。
- [ ] 手机与另一台设备实测公网 HTTPS 地址及深层链接。
- [ ] 无控制台错误、缺失图片、死链、泄露的密钥。
- [ ] 后端：后台发布后无需修改 HTML，另一浏览器能看到新文章。
- [ ] 后端：匿名用户访问草稿链接得到 404，不能访问管理功能。
- [ ] 后端：表单服务器校验、CSRF、输出转义、权限检查通过。
- [ ] 后端：重启及重新部署后数据仍存在；备份恢复实际验证。
- [ ] 后端：DEBUG=False，运行部署检查，生产服务不是 runserver。
- [ ] README 包含运行步骤、依赖版本、线上地址、已知限制。
- [ ] Git 记录体现真实迭代，开发日志与实际提交对应。
- [ ] 从干净目录可按 README 重建并运行。
- [ ] 能在五分钟内说明架构、演示功能、解释取舍和一次修复。
