## 验证记录

- 十页分别在 360、768、1440 CSS px 下检查 scrollWidth：均无横向溢出；每页一个 h1、一个 main。
- 人工截图观察桌面首页、手机列表与详情；截图存 docs/screenshots/。
- 键盘 Tab 聚焦跳转正文；Enter 后焦点为 main；继续 Tab 到主按钮，焦点轮廓 solid；Enter 成功打开发现页。
- 四个顶层页面在临时测试副本使用根字体 200% 检查，未横向溢出。检查过程中发现 body 固定 px 字号，已改为 1rem，使正文跟随字体设置。
- 对比度计算：主正文/背景 12.10:1；辅助正文/背景 5.63:1；紫色/选中底色 5.65:1；白字/主按钮 6.83:1；阅读正文/背景 6.97:1。以上是指定实色组合，不是整页自动无障碍认证。
- 装饰场景保持 aria-hidden，页面无图片加载依赖；本批次没有输入表单，不适用 label 检查。
- CSS 支持 reduced-motion；交互链接有可见焦点；导航触摸高度至少 44px。
